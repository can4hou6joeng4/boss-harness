## 任务输入与回执

- **发送回执**：直接发送被拒绝或回执不可读时保留来源草稿，不自动重发；失败提示按会话保存，在另一会话查看时标明来源标题，切回可查看原文。首页创建新会话时，若首条消息被内核明确拒绝，提示会说明会话已创建、草稿仍保留，并指出可从会话列表打开该会话核对，避免在首页重发而多建空会话；具体拒绝原因保存在该会话的错误记录中。重新读取会话也失败时，同时保留发送原因与读取错误，避免丢失消息是否被明确拒绝的说明。显式关闭提示或来源会话新回合开始后清除旧提示，关闭后台提示会清除其来源会话的记录、切回不再出现；记录仅保留在本次应用内存，重启后应核对会话记录。回执未确认不代表消息未受理，请先核对再决定是否重发，详见[发送回执与核对](USER_GUIDE.md#发送回执与核对)。
- **快速提问**：`⌘;`（Windows / Linux 为 `Ctrl+;`）或侧栏「快速提问」打开浮窗；已连接内核时，提问经既有 `thread/start` + `turn/start` 新建会话并立即发送，当前会话不受影响，成功后切换到新会话查看回复；等待期间未编辑输入时关闭浮窗并清空已提交内容，有过编辑时保留当前输入与浮窗，并提示原问题已提交到哪个会话。输入法组合期间的 Esc 不关闭浮窗，普通 Esc 或关闭按钮可关闭并保留输入。创建或发送失败时保留输入并显示真实原因，不自动重试，也不在本地生成任何回复；等待期间关闭浮窗即作废这次提交，重新打开后旧回执（提示、清空输入、关闭浮窗、复位提交态）一律不再生效。线路按当前会话 → 进程默认线路 → 目录同 provider 条目解析，`none` 或解析不出时明确拒绝。仅浏览器预览模式保留标注为示例的演示。
- **正在运行的回合**：`steering` 在当前工具批次后、下一次模型请求前生效；`follow-up` 等当前回合自然结束后按 FIFO 排队。
- **模型自动重试**：模型请求在首个输出前遇到瞬时失败时，会话区显示重试序号、倒计时与脱敏失败原因，并在恢复、失败或停止后给出结果；提示仅供观测，不提供重发入口。
- **失败可追溯**：回合以 `error` / `blocked` 结束时，原因码随回合记录持久化；重启或重新连接后，侧栏仍以红色状态点与「上次异常」标记该会话，悬停可查看原因码。

## 搜索与工具结果

- **搜索与沟通列表**：提交明确条件和页码；结果保留来源，未知分页和状态继续标为未知。
- **跨会话搜索**：`⌘K` 弹窗在输入至少 2 个字符后同时检索会话的标题、项目、消息正文与工具调用（工具名、来源编号、有界参数与结果摘要；不索引查询时间等本地化显示，默认不含已归档），消息命中显示项目、会话名、角色（你 / 助手 / 工具）与命中片段，片段与会话标题中的关键词直接标出，点击可直接打开对应会话并滚动到该消息（短暂描边提示），目标消息内的关键词同时高亮（点击、打开查找栏、离开会话或再次搜索后清除），工具命中会先展开目标工具块，让参数、来源编号与结果摘要等片段直接可见；`↑` / `↓` 在同一条序列中依次选择消息命中与会话结果，`Enter` 打开当前项。消息分区可勾选「含已归档」，归档会话随之纳入消息与标题搜索，命中行标注「已归档」（内核声明 `threadSearchArchived` 时提供）。搜索有界（最多 100 个会话、50 条消息、单会话 5 条），损坏或过大的会话跳过并计入不完整；达到展示上限后内核继续确认是否还有命中，确有未返回的命中、会话无法读取或扫描被会话数 / 文本预算截断时，在消息分区标注「仅显示部分结果」，无消息命中但搜索不完整时显示「消息搜索不完整」，命中数恰好等于上限且所有会话均可读的完整结果不标注。搜索词按 Unicode 码点计数，最多 200 个字符；超过时不再检索消息，只按标题与项目过滤，消息分区会说明「未搜索消息」。打开结果且查询至少 2 个字符时记入本地「最近搜索」（最多 5 条，可点击回填或一键清除，存储不可用时自动跳过）。从搜索结果或通知发起的一次性定位只服务那次跳转：在消息载入完成前切换会话、新建任务或切到其它页面会取消定位，切回时不再自动滚动与高亮；定位一旦执行即被消费。旧内核未声明 `threadSearch` 时只按标题与项目搜索。
- **删除时的在途读取**：收到会话删除通知后，该会话正在恢复的历史页、大正文与缓冲增量会作废，迟到的成功或错误不再写回；当前连接内不重新读取已删除会话。其他会话仍可正常恢复，重新连接会重置这项连接内记录。
- **删除后的当前视图**：内核在删除回执之前广播删除通知。回执未确认（丢失、超时或形状不符）时列表按约定提示核对，但被删除的正是当前会话时立即回到首页，输入区不再向已不存在的会话发送；该会话的消息缓存、队列投影、失败提示、回合标识、记住的审批、推理档位设置、后台完成标记与审批提交状态一并遗忘，删除前发出的队列读取与推理设置读取也不再写回。手动与自动审批的迟到回执不会重建该会话的消息或审批提示，也不会触发恢复读取；切换会话与删除其他会话不影响原有回执的结算。固定在该会话上的上下文、用量、导出、分支与回退弹窗随删除通知一并收起，不再对已删除会话读取或提交操作；固定在其他会话的弹窗不受影响。上下文面板、分支弹窗与推理档位的状态同样随删除遗忘：不再按 1.5 秒 / 2 秒轮询已删除会话，删除时在途的读取、计划、开始、取消、切换与档位保存回执也不会把它放回状态或轮询，其他会话继续正常刷新；断连重连后按连接内记录重置。重复删除通知的清理保持幂等；删除不撤销已受理的审批或工具操作。
- **工具恢复建议**：工具完成结果带有恢复建议时，展开卡片即可查看；实时结果与重新读取的历史使用相同字段，消息复制与「含工具、审批与思考」查找也包含该建议。建议只用于说明下一步，不会自动重试工具或代替审批。
- **工具来源**：工具卡显示来源编号与查询时间（按本机时区）。时间缺失、空白或不可解析时只显示来源编号，不显示 `Invalid Date`；消息「复制」与标题栏轻量导出在「来源编号」后输出 UTC ISO「查询于」，整秒省略 `.000`，便于核对数据新鲜度与跨天分享。
- **大工具结果**：结果超过 64 KiB 时不在会话读取中内联正文，工具卡改为「查看完整结构化结果（分段）」，可按需读取第一段、上一段与下一段（每次最多 16,384 字符，计数按 Unicode 码点）。分段面板提供「复制完整结果」：按现有只读 `thread/item/result/read` 逐段读取并拼接，读取期间显示已读字符数与总字符数、禁用分页按钮；读取期间另提供「取消」，取消后立即恢复操作并提示「已取消整体复制，未写入剪贴板」，剩余分段不再请求，离开会话或收起工具卡导致面板卸载时同样中止读取；成功后一次性写入剪贴板并显示字符数，写入失败显示可读原因且不写入部分内容。结果超过 1,000,000 字符时在发起请求前拒绝并提示分段查看；任一分段失败、偏移不连续、提前结束或总长度与 `resultRef.characterLength` 不一致时整体失败。引用与分块读取使用同一份规范化结果文本；若引用已过期且内核给出合法 `currentRef`，界面提示重新打开聊天核对当前引用，不自动改写引用、不混用不同版本的分段；引用数据非法时仍显示通用错误。
- **大正文恢复**：超过 64 KiB 的会话正文或思考字段以 `textRef` / `thinkingRef` 保存，恢复时逐段校验引用归属、长度与摘要后才展示。一次恢复还共享分页总预算，逐条限流无法让多个大字段累加成大量请求；预算耗尽会明确失败，不展示部分正文。若内核返回 `STALE_CONTENT` 且带合法 `currentRef`，界面提示重新打开会话并核对当前引用；引用数据非法时仍按原始通用错误展示，不自动改写引用或拼接不同版本的正文。

## 审批、通知与停止

- **停止任务**：运行中的回合可用输入框旁的停止按钮中断。停止请求携带界面正在展示的回合：该回合已被排队的后续回合替代时，内核明确拒绝并保持新回合运行，不会把停止落到用户没看到的新回合上。停止回执失败或内核回报没有可停止的回合时，提示按发起停止的会话保存：回执到达前切走会标明所属会话，切回后仍能看到原文；内核明确拒绝与回执未确认分开说明，两者都不自动重发。重新读取会话也失败时，同时保留停止原因与读取错误，避免误以为停止已确认。受理停止不产生失败提示，重新发起回合会清除该会话的旧提示；停止请求在途或已被受理、回合尚未结束时，按钮禁用并显示「正在停止任务」，失败或内核回报没有可停止回合时立即恢复，重复点击不会发出第二个请求，也不会误报「未找到可停止的任务」；多个会话同时停止时各自保持该状态，切换会话不丢失。
- **会话内审批**：聊天中的敏感操作审批卡在等待决定期间显示到期倒计时（取内核 `approval/requested` 事件与会话记录中的 `deadline`，内核以 Unix 秒返回，界面换算为毫秒后显示；每 15 秒刷新，文案为已过期 / 即将过期 / N 分钟后 / N 小时后）；剩余不足 5 分钟转警示色、到期转错误色，已处理后不再显示。到期时间缺失或不可读时不显示倒计时，不把未知时间标成正常；展示不影响审批决定与内核超时行为。审批回执不可读或断连时，手动与自动批准均提示结果尚未确认，先核对审批与工具结果，不要直接重复提交，不把未知说成确定未送达。自动批准的失败与核对提示也保存在来源会话的输入区，切走后不显示到另一会话，切回仍可查看。先到审批结论的保护：迟到自动回执保留已处理卡片；切回会话且读取失败时也保留已知结论。自动批准被内核明确拒绝时按拒绝码说明原因（回合已结束或归档、已按相反决策处理、审批不存在或无效、仍由活动回合持有、已失效），不再一律写「请手动确认」：审批已不再接受裁决时刷新一次会话让持久化结论落到卡片，仍由活动回合持有时只提示等待或停止、不重读全量快照；已有同一审批结论时说明界面未重新开放操作，未知回执继续要求先核对审批与工具结果。真实会话里的审批缺少有效标识时按钮禁用并提示刷新会话核对，不会把点击记成已批准；示例模式的无标识卡片仍按本地演示处理。审批结论不代表工具执行成功，仍须核对工具结果，详见[审批回执与核对](USER_GUIDE.md#审批回执与核对)。参数本身无法作为命令行传递（例如字符串里含空字符）的调用不会弹出审批卡：内核在审批之前就以参数错误拒绝，工具条目会说明是无法传递的字符，而不是笼统的参数不符。已发出审批、但子进程在实际启动前失败的调用记为「未执行」并暂停本回合，不会显示成「可能已生效」。
- **通知面板**：标题栏铃铛或 `⌘⇧A`（Windows / Linux 为 `Ctrl+Shift+A`）打开后读取内核 `approval/list`（最多 100 条），按内核顺序列出跨会话待审批的 `boss_hr_greet` 调用，并按会话分组（组标题显示「项目名 · 会话标题」与数量，不同项目下的同名会话可区分），行内显示工具名、摘要与到期提示（已过期 / 即将过期 / N 分钟后 / N 小时后）；点击条目打开对应会话并滚动定位到该审批卡（短暂描边提示），会话不在当前列表时标注不可点击；`↑` / `↓` 在可点击条目间循环移动焦点，`Home` / `End` 跳到首尾，`Enter` 打开当前条目。读取失败与「没有待审批」分开呈现，可重试或刷新；加载中显示读取状态。面板打开期间每 15 秒静默重读，新审批、已处理项与到期提示随之更新（页面隐藏时暂停，窗口聚焦时立即读取）；收到内核 `approval/requested` / `approval/decided` 通知后约 250 毫秒内再静默读取一次（连续事件合并），后台刷新失败保留当前列表。侧栏铃铛显示待审批数量（0 条隐藏、超过 9 条显示「9+」），连接内核后立即读取并每 30 秒刷新，收到内核 `approval/requested` / `approval/decided` 通知后约 250 毫秒内再读一次（连续事件合并），窗口重新获得焦点时也刷新，断开或示例模式下清除；读取失败保留上一次数量。窗口不在前台且系统支持通知时，内核 `approval/requested` 还会触发一条系统通知（标题为工具名、正文为该审批摘要），点击后恢复并聚焦工作台，并在定位字段齐全时直接打开对应会话、滚动到该审批卡（会话不在当前列表时只聚焦窗口）；同一 approvalId 只提醒一次，系统不支持或发送失败只影响提醒，不影响窗口内通知与审批流程。运行不少于 20 秒的回合结束时，同样会在窗口未聚焦时弹出系统通知（标题按完成 / 中断 / 暂停 / 出错区分，正文为运行时长），点击后恢复并聚焦工作台，并直接打开该回合所属会话（会话不在当前列表时只聚焦窗口）；短回合与无法配对开始时间的回合不提醒。连接内核后待审批数量还会同步到应用图标徽标（系统支持时；归零或断开时清除）。设置 → 通知提供「发送测试通知」，经主进程确认系统支持后发送一条测试通知，并按返回值分别提示已请求展示、系统不支持、系统支持但发送失败或返回结果无法识别；只有「已请求展示」会建议留意桌面提醒。设置 → 通知还可开启「审批提示音」（默认关闭）：新审批请求到达时播放两声短提示音，连续请求至少间隔 1.5 秒；不支持 Web Audio 或自动播放受限时静默跳过，不影响通知与列表刷新。

## 会话、查找与导航

- **会话重命名**：标题栏或侧栏打开「更改显示名称」时，名称经既有 `thread/name/set` 写入内核并随会话持久化，成功后立即更新列表与当前会话标题，并删除只存在于本机的旧别名；失败时保留弹窗与输入，按内核错误码显示真实原因，不静默回退成本地成功。浏览器预览等没有内核桥接的场景仍只保存本机显示名称，弹窗明确标注该差异。旧版本遗留的本机别名会在连接内核、会话列表就绪后迁移：与内核标题一致或为空的别名直接删除，其余逐个写入内核并在成功后删除本机别名，失败保留别名、不提示并在下次启动重试；每次启动最多迁移 50 个，超过内核 500 字符上限的名称保持本机显示。搜索对话框的消息命中与会话命中统一使用同一显示标题。
- **会话内查找**：在聊天中按 `⌘F` / `Ctrl+F` 打开查找栏，按用户输入、模型段落与要点匹配当前消息（NFKC 归一化、不区分大小写），显示匹配数量，用 `Enter` / `Shift+Enter` 前后跳转并滚动到对应消息，`Esc` 关闭（查找栏打开时焦点可在任意位置，关闭只消费这次 `Esc`，不计入双击 `Esc` 的分支回退）；空查询不选中任何消息。查找栏打开后焦点被点到别处，再按 `⌘F` 会重新聚焦查找框并全选现有关键词，键入即替换，不会落进聊天草稿。默认只匹配可见正文，勾选「含工具、审批与思考」后还会匹配思考内容、工具名称、状态徽标、执行耗时、输入、来源编号、来源查询时间（按工具卡渲染的本地时间）、错误码、恢复建议、结果与结构化输出，以及审批卡说明、结论与期限（审批有结论后卡片不再显示倒计时，期限也不参与匹配）；审批卡与状态徽标默认可见，命中时不展开折叠块。切换后立即重算；命中的文字在消息中高亮，当前匹配使用另一种颜色，关闭查找即清除（浏览器不支持时退化为只保留消息描边）。计数与高亮只覆盖当前匹配范围：未勾选详情时默认收起的思考块与工具块内文字不计入，勾选后计数包含折叠内容，跳转到该消息时自动展开对应块，让当前命中可见。
- **弹窗焦点**：打开弹窗时优先聚焦单行输入，其次正文文本域（「编辑排队消息」「编辑技能」等会把光标放到正文末尾），其余情况才落在第一个可聚焦控件；焦点从弹窗外部被拉回时不改写已有选区。Esc 关闭、Tab 循环与关闭按钮行为不变。
- **消息反馈**：代理消息工具栏的「有帮助 / 需要改进」标记按「会话 id + 消息 id」写入本机界面偏好（`boss-harness.ui.messageFeedback`），切换会话或重启应用后保留；再点同一按钮取消并删除存储条目，可改为另一种标记，按钮通过 `aria-pressed` 暴露选中状态。点击后短暂显示「已记录反馈，仅保存在本机」，再次点击显示已取消；本机存储不可用（隐私模式、配额用尽）时如实提示重启后会丢失。反馈不发送给模型或招聘平台，也不进入会话导出。读取时只接受 `up` / `down` 与合法键，损坏条目安全丢弃；最多保留 2,000 条，超出按写入顺序淘汰最早条目。
- **待你处理**：侧栏顶部聚合上一回合异常、等待预检与存在暂停队列的会话，按最近更新排序，行内操作与其他分组一致；已归档或已隐藏的会话默认不出现，没有待处理会话时分组自动隐藏。

## 队列与长会话

- **待处理队列可见**：尚未形成回合的排队、投递中与暂停消息按会话汇总，侧栏以「队列 N」徽标显示数量；存在暂停项时改显警示色「暂停 N」，悬停可查看排队、投递中与暂停的分类数量。徽标随内核队列事件即时更新：收到 `queue/updated`、转向应用或回合开始 / 收尾时，用同一次 `queue/list` 读取结果同步对应会话的徽标（投影被截断时只同步待处理总数，分类留给下一次会话列表刷新校正），排队、撤回或暂停后无需等到会话列表刷新。同一队列项按最新状态归并，已终结或撤回的消息不再计入，重启后仍能从会话记录恢复。队列项携带技能时，面板显示技能名称（目录缺失时回退 id），导出也会列出技能 id，便于在消息成为回合前核对。队列面板标题行提供「刷新」按钮，手动重读当前会话的 `queue/list` 并更新列表与总数 / 截断信息；刷新失败时显示原因并保留上一次内容，不显示成空队列。正文被截断（`inputTruncated`）的队列项另提供「查看完整输入」，经只读 `queue/get` 读取持久化正文并以模态展示，关闭不会重新提交或修改队列；读取失败时保留预览并显示原因。模态同时列出该项的技能与自动压缩覆盖，并提供「复制完整输入」，复制结果与失败原因如实显示。仍在排队（`queued`）的消息可在投递前编辑正文（需内核声明 `queueUpdate`）：编辑保留队列项 id、技能与压缩覆盖，被截断的正文会先读取完整输入再进入编辑器；已投递、投递中、暂停与已撤回的项不可编辑。内核声明 `queueSteer` 时，排队中的后续消息还可「转为当前回合」：内核原子改为 steering，不新增队列项；带技能或自动压缩覆盖的项会被拒绝，没有运行回合、断连或批量操作在途时按钮禁用并说明原因。队列项离开列表（投递、撤回或重排）后，属于它的「查看完整输入」与「编辑排队消息」立即关闭，不会在后续入队时带着旧草稿重新出现。本机内核断开时面板标注状态可能已过期并禁用刷新，恢复连接后由既有事件与重连流程重新读取。
- **长会话**：可读取预算、规划并生成摘要、查看冻结快照，或从已结束回合创建分支；原始历史不因摘要被删除。会话上下文面板还可为下一条发送设置自动压缩覆盖（开关、触发阈值、保留目标），直接发送与「排到后续回合」的队列消息都会携带，发送后恢复默认（覆盖被消耗或被清除后表单回到当前内核默认值，内核默认值尚未读出时回到初始占位值），不写入会话；发送被内核明确拒绝时覆盖写回并继续生效，回执未知或发送成功才视为已消耗；转向与续接消息不使用该覆盖。会话被删除时，该会话的未应用草稿、已应用覆盖与手动改动标记一并遗忘，删除的正是当前会话时表单回到默认占位值；其他会话不受影响。内核声明 `autoCompactionConfig` 时，设置 →「上下文」可查看并保存自动压缩的持久默认值：写入内核状态目录 `config.json`（原子替换、保留其他顶层键），重启后生效；`BOSS_HARNESS_COMPACTION` 显式设置时优先，此时界面只读并在保存请求上得到明确拒绝。每次进入该分区都会重读内核值：读取期间显示读取态而不是旧表单，回执只作用于本轮读取；保存期间开关与数值输入随保存按钮一起锁定，避免回执覆盖保存中的编辑。`config/read` 的 `autoCompactionSource` 标明来源（`environment` / `stored` / `default` / `explicit`），策略中的摘要 provider、model、effort 仍由启动配置决定。上下文面板在自动压缩覆盖与手动规划的保留目标不低于当前输入预算时给出提示：此时压缩后仍可能超出预算，达到阈值时通常没有更早的可压缩内容。设置 →「上下文」读取内核默认值时一并取得当前模型的上下文窗口，保留目标不低于该窗口时在策略来源旁提示；窗口缺失、无效、内核断连或重新读取期间不提示。本机内核断开时，面板保留上次读取的预算、工作区说明与任务信息并标注可能已过期，重连后重新读取并核对。队列读取同样有界：会话读取与 `queue/list` 优先返回暂停项，再返回最近的排队 / 投递中项（待处理项单次最多 200 项），名额允许时另返回最近的已终结项；长正文只给预览，`queue/get` 按单项读取完整内容。
- **会话内分支**：内核支持时，可在「会话分支」中查看分支端点、切换到其他分支或从已结束回合重新开始；原回合全部保留可切回，模型只看到当前分支。可选为被放弃分支生成摘要（会调用模型，默认关闭），摘要标注可展开查看模型生成的正文；运行、摘要或排队期间不可切换。摘要进度与「取消摘要」归属当前任务，旧任务或旧连接的迟到轮询不会替换它；取消回执与收尾同样绑定发起时的连接与任务：旧回执不释放新取消的等待状态，不覆盖新任务进度或提示，新任务也不继承旧任务的取消锁；取消受理后仍需等待任务终态，断连后先恢复连接并核对，不自动重发。切换途中断连后，旧队列回执不会继续提交切换，旧切换回执不会关闭重新打开的窗口；恢复连接后先核对当前位置，再按需确认，不会自动重试。会话在切换途中被删除时，回执不再重读、写回或刷新该会话，其他会话的切换不受影响。内核确认切换后重新读取会话失败时，只说明分支已切换、会话重读失败、分支位置以内核为准，不报「切换结果尚未确认」；未提交、明确拒绝与回执未知三类失败分别说明。分支端点与当前分支回合分多次读取，每一页响应都带有内核计算该页时的当前位置：各页位置不一致（读取期间切换了分支或开始了新回合，包括切走又切回）时，界面不展示混用的结果，自动重读一遍；位置变化通常是一次性的，重读后各页一致就照常展示，仍不一致才提示稍后刷新，不会反复重读。单页读取同样核对，位置稳定时不增加请求。旧内核的回合页不带位置时，只在翻页后用端点再核对一次。目标会话有回合开始时分支列表随即重读：运行中的回合显示为未结束的当前端点，不再把上一个回合标成当前位置直到回合结束。读取失败时弹窗保留上次成功读取的列表，并在错误提示下方注明它是旧结果：当前位置标记与可切换目标可能已变化，刷新成功后再据此操作。
内核明确表示摘要任务已不存在时，取消入口收敛本地状态并说明不会重放；其他失败仍保留回执未知提示。任务开始应答缺失、终态引用存在但详情不可读，或运行中任务连续无法核对时，面板同样会说明已停止跟踪并解除本地界面锁，可重新生成计划；这只是本地收敛，内核仍是并发与任务状态的权威，内核仍可能拒绝新的并发摘要。

## 技能与工作区说明

- **技能上下文**：从工作区 `.boss-harness/skills/<id>/SKILL.md`（旧 `.boss-cli/skills` 仍兼容读取） 选择技能，内容只作为该回合提示上下文，不执行目录脚本，也不扩大工具清单。内核声明 `skillsRead` 时，「技能与工具」页会列出工作区技能，并支持只读查看单个 `SKILL.md` 正文（最多 64 KiB，不写入会话）；目录未连接、加载中或读取失败会分别标注。页面同时显示当前生效的技能目录，来源为旧 `.boss-cli/skills` 时提示迁移；选中技能可直接预选进新会话草稿，不会自动发送。内核声明 `skillsCreate` 时还可新建技能：只创建不覆盖，写入当前生效目录；id 限定小写字母、数字、下划线与连字符，正文不超过 64 KiB，表单实时显示写入路径与字节计数。内核声明 `skillsWrite` 时还可编辑已有技能：保存必须携带读取时的摘要，文件被外部修改后拒绝覆盖并提示重新读取，草稿不会被自动重试。内核声明 `skillsDelete` 时还可二次确认后删除技能：只删除仅包含 `SKILL.md` 的技能目录，目录里还有脚本或素材时拒绝，摘要变化时不会删除任何内容。目录中无法安全读取的 `SKILL.md`（缺失、符号链接、超过 64 KiB、非 UTF-8 或不可读）会以「未能加载」列表显示原因，且不会进入技能列表或被注入；未加载项清单不受可加载技能数量影响，超过展示或枚举上限时页面如实说明清单不完整。手工建立的旧技能目录名（如含大写、空格或中文）仍可查看、编辑与删除；新建技能继续使用严格 id。输入框技能菜单可按 id、名称与描述筛选，筛选不改变已选技能；已选技能还会在输入区以标签列出（悬停显示描述），可直接移除；已不在当前目录中的技能仍显示并标注不可用，不会静默丢弃；内核断开、目录加载中或读取失败时不会把已选技能标成不可用，只有成功读取的目录（包括确认为空）才据此标注。目录存在未能加载的技能时，菜单底部会显示数量并指向本页查看原因。页面本身也提供筛选，可按技能与未加载项定位，并显示匹配数量。回合记录已保存实际注入的技能 id，因此每个用户消息气泡下方会回显「本回合技能」（旧内核或旧会话没有该记录时不显示），点击标签可直接打开「技能与工具」并选中该技能；会话导出也会在回合信息中列出技能 id。
- **工作区常驻说明**：若工作区存在 `.boss-harness/CONTEXT.md`（旧 `.boss-cli/CONTEXT.md` 兼容），每回合组装系统提示时读取不超过 8 KiB 的 UTF-8 文本，用于城市、薪资、硬性技能等长期偏好；内容只是上下文，不改变工具权限、审批要求或只读限制，编辑后下一回合生效。会话上下文面板会显示该文件是否已加载、为空或已忽略（超限 / 不可读）；旧内核不返回该状态时不显示。内核声明 `workspaceInstructionsEdit` 时，面板可直接查看并保存该文件：UTF-8、不超过 8 KiB、拒绝符号链接，保存固定写入首选 `.boss-harness/CONTEXT.md`（旧位置仍生效时，保存后旧文件不再被读取），经临时文件原子替换，下一回合生效；保存不改变工具权限、审批要求或只读限制。「技能与工具」页也提供同一入口，不用先打开会话即可查看状态并编辑；编辑器与面板关闭时会提示未保存修改。

## 上下文与用量

- **系统提示构成**：会话上下文面板显示本次请求系统提示的总字节数与分段明细（工具与运行说明、用户选择的技能、工作区说明、只读限制），分段与实际组装同源，只给规模不给正文；运行中的请求可能只显示总数，旧内核不返回该信息。
- **输入预算构成**：会话上下文面板在预算条下展示估算输入的去向（系统提示、消息历史、工具定义、选项），按比例分段并标注各项估算 token 数；应用历史用量校准时改显「历史用量基线 + 新增消息」，并说明基线已包含系统提示、工具与历史消息、无法再拆分。字段缺失、非法或全为 0 时不显示，估算不是账单。
- **会话用量**：内核支持时，可在聊天菜单「会话用量」查看本会话合计、摘要任务与每回合的 provider 上报 token（输入、缓存读写、输出、推理）；「全部记录」视图另按相邻两次已验证请求估算缓存未命中 token 与次数（取两次输入的较小值减去本次缓存读取，只累计超过 1024 的部分，压缩或分支摘要后重置基线），「当前分支」视图不统计；每回合标注该回合实际使用的自动压缩策略与从开始到结束的用时（运行中显示「进行中」，时间缺失或非法时不显示），并显示该回合注入的技能 id（旧内核或没有技能时不显示），摘要任务可按任务查看来源、关联回合、触发原因与用量，压缩摘要另标注记录中覆盖到的回合，当前分支上验证通过并生效的压缩摘要任务标注「当前生效」。未上报的字段显示为「—」，不做估算，费用不计价。工具栏的「复制 CSV」把当前视图已加载的用量复制为带表头的 CSV：每行标注类别（合计、缓存未命中、摘要任务、摘要任务明细、回合）与未计入原因，未知数值留空而不是写成 0，按需加引号并转义，以 `= + - @` 开头的内容加前导单引号避免被电子表格当成公式；数据被截断时在末尾注明范围。「当前分支」视图分多页读取时逐页核对内核报告的当前位置：读取期间切换了分支或开始了新回合，各页分属不同位置（合计来自第一页、明细由两条分支拼成，且回合数相同时不会重复），界面放弃本次结果并提示刷新；「全部记录」不随位置变化，不受影响。「全部记录 / 当前分支」范围单选组支持方向键循环切换并让焦点跟随选中项，按住方向键不会重复读取，Tab 在组内只停一次。导出会话时同样附上摘要任务明细；压缩摘要与分支摘要条目还会标注来源任务编号（压缩摘要另附触发原因）。

## 界面偏好与恢复

- **运行状态**：按 `⌘⇧K` 打开「运行状态」，核对内核线路、并发与保留回合、待审批调用、工具与模型目录；当前会话的队列摘要也在其中。面板打开时会随回合、审批与队列事件自动刷新，只展示本地内核返回的事实，当前版本不接入 MCP。状态、阶段、审批策略与容量来源以中文显示，未知取值保留原文并加「」标注。运行中的回合与摘要任务可逐项核对 `task/read` 持久记录（状态、归属与恢复策略）；核对只读，不会恢复或重放任务。
- **窗口状态恢复**：主窗口的位置、尺寸与最大化状态在移动、缩放后防抖保存，关闭前再保存一次；启动时按当前显示器的工作区校验，窗口至少要有 80×40 像素落在某块工作区才恢复，否则回到默认尺寸并交给系统居中；显示器变小或分辨率变化后，窗口收敛到重叠最多的工作区，宽高不超过该工作区。保存使用同目录独占临时文件并原子替换，状态文件损坏或字段越界时整体忽略，不影响启动。
- **界面崩溃恢复**：主窗口渲染进程意外退出（崩溃、内存不足或被系统终止）时自动重新加载界面，120 秒内最多 2 次；连续失败后显示无脚本的静态诊断页，列出退出原因与退出码，并说明会话与回合记录保存在本地内核、重开应用可继续。正常退出不触发该恢复路径；界面加载失败仍走原有诊断页。
- **内核启动失败提示**：本地内核未能完成启动时，提示条给出失败原因与自动重试状态：握手完成前就失败与「就绪后断开」分开表述，重试预算用尽后不再显示「正在恢复连接」；握手前失败时主进程用与内核相同的解释器、工作目录与环境运行一次只读自检，把错误项的检查项名称、说明、建议与固定检查码同时显示在提示条与「设置 → 模型与连接」，并在报告带版本字段时于明细前显示内核、协议与 Python 版本；报告协议版本与桌面常量不一致时额外提示两侧版本与「可能来自不同构建」，字段缺失或一致时不显示该提示；字段不合规时整份报告不展示，自检未发现错误时提示逐项排查内核依赖、状态目录等运行条件，存在警告时同时列出警告的检查项名称、说明与检查码并注明可能不影响启动；报告的错误全部为缺少模型 SDK 时，恢复建议改为安装内核依赖。自检区域提供「复制自检结果」，只汇总界面已展示的标题、版本、检查项与建议；写入成功或失败都有回执，新自检结论会作废旧回执。界面不展示内核 stderr、异常原文、端点、凭据或本机路径；曾有会话就绪后断开时保留「结果未确认的对外操作请先核对平台状态」。显式重新连接会丢弃旧自检结果，恢复连接后提示自动清除。
- **手动运行配置自检**：「设置 → 模型与连接」的「本地配置自检」行可在任意连接状态运行与启动失败自检相同的只读命令；解释器、工作目录与环境沿用应用启动时的选择，渲染层不传任何参数。运行中按钮禁用并显示进度，连续点击共用同一份在途结论，启动失败自检尚未结束时先等它退出，同一时刻只保留一个自检进程；退出应用时会结束仍在运行的自检进程。结果到达时显示与 `--format text` 同口径的总体结论与本机运行时刻（「通过」「通过，N 项警告」或「发现 N 个错误、M 项警告」），按「错误 → 警告 → 通过」列出名称、说明与固定检查码，报告带版本字段时显示内核、协议与 Python 版本，协议不一致时同样提示；超时、进程启动失败或输出不合规沿用固定说明，不显示结论。结果不持久化，重新进入页面不会显示旧的时刻。结果可复制为纯文本，只含界面已展示的字段，标题包含运行时刻与结论，不可用结果把固定说明一并复制；不包含 stderr、异常原文、端点、凭据或本机路径，新结论会作废旧回执。自检不调用模型、不运行招聘 CLI、不访问招聘平台，通过不代表这些能力已可用。
- **界面异常兜底**：组件在渲染阶段抛出异常时不再白屏。应用根节点有一层错误边界；会话区另有局部边界，会话区渲染失败只影响会话区，侧边栏、导航和其他会话仍可使用，切换会话或点「重试」即重新挂载并恢复。兜底界面显示单行摘要、「重试」「重新加载」「复制详情」三个操作，并说明会话与内核仍在运行、重试不会删除本地会话。复制内容包含出错区域、时间、摘要、堆栈与 React 组件栈，都不超过固定长度；抛出值为字符串、普通对象、`undefined` 等非 `Error` 时也能得到可读描述，循环引用与 BigInt 等无法序列化的值退回默认文案。剪贴板不可用时如实提示；连续复制时只有最近一次操作可以更新提示，重试或出现新错误后旧回执失效。事件处理器与异步回调中的异常不经过错误边界，行为不变。
- **主题跟随系统**：设置 → 外观的主题支持「跟随系统 / 浅色 / 深色」三档，选择写入 `boss-harness.ui.theme` 并在下次启动沿用；旧版本保存的 `light` / `dark` 继续作为固定外观生效，缺失、空白或损坏的值回退为跟随系统。跟随系统时监听 `prefers-color-scheme`，系统切换深色 / 浅色后界面立即更新；固定浅色或深色时不跟随。首屏在 React 挂载前按存储偏好与系统外观决定主题，避免保存浅色而系统深色时先深后浅的闪烁。导航栏的快捷切换仍在浅色 / 深色之间切换，并把选择固定为对应外观。
- **界面偏好备份**：设置 → 数据管理可把字体大小、紧凑会话、动态效果、审批提示音与主题导出为 `boss-harness-ui-preferences.json`，并可从同一格式导入恢复；导入立即应用并写入本机存储，成功提示实际导入项数，本机存储不可用时说明只应用到当前窗口、无法持久化。导入只接受 `version: 1`、`scope: "boss-harness.ui"` 与白名单键，字体大小限 12–16；损坏 JSON、错误版本或作用域、非法值、空文件与超过 64 KiB 的文件整体拒绝且不改动现有偏好，未知键忽略；旧版没有主题键的导出文件仍可导入其余字段。
- **草稿本地保留**：输入区正文、已选技能、首页选中项目与历史调取前的原稿写入本机界面存储（`boss-harness.ui.composerDrafts`），应用重启、窗口重载或升级后分别恢复；发送成功后对应条目随输入清空。附件原文、提交中与队列待核对状态均不落盘；空草稿删除条目，最多保留 20 个最近会话草稿，单条正文超过 100000 字符不持久化，不静默截断。输入停顿 300ms 后写回，关闭或重载窗口前补写一次；存储不可用、配额已满或内容损坏时回退为空草稿，输入与发送不受影响。
- **减少动态效果**：设置 → 外观开启「减少动态效果」，或系统偏好为 `prefers-reduced-motion: reduce` 时，界面过渡与动画降到接近零，聊天区的查找命中跳转、搜索 / 审批定位消息与「回到底部」也改为即时滚动；两者都未开启时保持平滑滚动。滚动行为由 `scrollMotion` 纯函数统一解析，不依赖各组件自行判断，环境无法读取系统偏好时退回应用设置。
- **视觉语言**：界面以暖纸色（浅色）与深绿黑（深色）为画布，标题使用衬线展示字体，正文使用无衬线、代码使用等宽字体；颜色、圆角、间距与字体统一由 `styles/tokens.css` 的语义令牌给出，组件不直接写死主题色。视觉参考 Elanor 设计系统的暖纸色、细边框与克制留白；主题三态、密度、字号与减少动态效果的行为不变，正文 / 背景、次要文字 / 背景与强调色 / 背景的对比度经离线探针按 WCAG AA 校验。
- **关于页环境信息**：设置 → 关于展示应用版本（构建时从根 `package.json` 注入）、协议版本、Electron / Chromium / Node 版本、平台与内核连接状态；缺失或空白的字段统一显示「未知」，不编造版本号。平台标识映射为 macOS / Windows / Linux，其余原样显示。「复制诊断信息」把同一组字段生成纯文本并写入剪贴板，成功与失败如实提示，文本不含路径、凭据或会话内容。展示字段与诊断文本由纯函数生成，便于离线核对。

## 导出与资料库

- **导出会话**：内核支持时，可在聊天菜单「导出会话…」把当前分支或完整日志保存为 Markdown / JSON / 自包含 HTML，用于复盘与问题报告。默认脱敏：不导出凭据、令牌、环境变量、本机路径与附件内容，工具结果只保留调用名、执行状态、执行耗时与结构，个人信息按工具数据中识别到的字段值打码（未出现在工具数据中的姓名可能无法识别）；勾选「包含工具结果明文」需确认风险提示。HTML 内联样式、禁止脚本与外部资源，可直接用浏览器打开或打印；Markdown 的单行元数据会转义链接、图片、原生 HTML、强调与表格定界符，正文放在按内容加长的代码围栏中；JSON 以 `schema: boss-harness-session-export/1` 标识格式与版本，供下游判断兼容性；旧内核回退的本地 Markdown 导出会把标题折叠为单行并限制 200 个字符。文件经系统保存对话框写入，超出上限时截断并标注。写入先在同一目录创建唯一临时文件（0600、不跟随符号链接），刷新到磁盘后再原子替换目标：覆盖已有导出时写入中断或失败不会把旧文件截断，失败会清理临时文件并如实报告原因。回合头标注开始、结束与用时（时间可解析时），工具审批信息标注决定时间或待审批期限。导出同时附带队列表状态：未形成回合的排队、投递中、暂停与已撤回消息（含暂停项的失败码与「输入是否已写入会话」，暂停项即使较早也优先保留），该状态与会话绑定，不受分支视图影响。用量来源字段（`provider` 与模型名）同样按默认规则脱敏，摘要任务明细会标注当前分支上生效的压缩摘要任务。
- **资料库汇总**：资料库页面同时列出当前会话的文件变更引用与工具来源。文件按完整路径去重，同一路径跨消息、跨同一条消息的 `initialFiles` / `extraFiles` 合并为一条，累计新增 / 删除行数与出现次数，保留首次出现的消息与回合；非法行数按 0 处理，空路径跳过，结果按路径稳定排序。工具来源来自内核为每次工具调用生成的 `toolUse.source`，按 `ref` 去重，查询时间可解析时按时间倒序、否则按 `ref` 字典序兜底，缺失工具名显示「未知工具」，空编号跳过。两类数据共用搜索框（NFKC 归一化、不区分大小写），分别显示「命中数 / 总数」；文件详情展示完整路径、目录、累计变更与来源回合，并可复制路径。内核尚未提供文件读取接口，页面明确说明不能在线预览内容，不虚构文件正文。
